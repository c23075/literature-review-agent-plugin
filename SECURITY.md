# Security

## Reporting a problem
Open a private advisory on this repository (Security → Report a vulnerability). Please don't open a
public issue. A problem in the sandbox or the plugin contract belongs with
[Cairnward](https://github.com/c23075/possessed-incantation) instead. This is a one-person project,
so there's no response time promise.

## What's been reviewed
Only the assistant that wrote the code has reviewed its security. There's been no outside review or
penetration test.

## Known limits
A paper can carry instructions for the model, and they can still reach an answer: see
[what's known to go wrong](README.md#known-problems) and `evals/injection`.

## Versions
Only the latest version gets fixes.
